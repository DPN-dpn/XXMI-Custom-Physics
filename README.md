## 📖 프로젝트 개요

XXMI(GIMI, SRMI, ZZMI, WWMI 등) 캐릭터 모딩 시 원본 모델에 없던 파츠를 새롭게 추가하거나 체형을 크게 변경하는 경우가 많습니다.
* **남캐 ➔ 여캐 TS 모드의 가슴(Breasts)**
* **단발 ➔ 장발(Long Hair), 포니테일(Ponytail), 트윈테일(Twin-tails)**
* **바지 ➔ 스커트(Skirt), 코트, 망토 등**

기존에는 바닐라 모델 뼈대에 해당 물리 본이 없어 몸통이나 머리 본에 단단하게 통째로 웨이트를 칠해 인게임에서 파츠가 뻣뻣하게 굳어버리거나, 단순 사인파 쉐이더로 인해 표면이 젤리처럼 꿀렁거리며 장신구까지 고무처럼 늘어나는 문제가 있었습니다.

**XXMI Custom Physics**는 블렌더 내에서 정밀한 가상 물리 스켈레톤(`XXMI_Breast_Rig`)을 자동 배치하고, 3DMigoto Compute Shader(HLSL)를 통해 인게임에서 다관절 FK 회전과 스키닝을 실시간 연산하여 **실제 물리 뼈대가 들어간 것과 같은 자연스럽고 입체적인 모핑**을 완벽하게 구현합니다.

## ✨ 핵심 기능

### 1. 4단계 직관적 워크플로우
복잡한 수동 본 리깅이나 버텍스 그룹 세팅 없이 **단 4단계 버튼 클릭**만으로 자연스러운 물리 설정이 완료됩니다.
1. **`1. 선택 영역을 가슴으로 등록`**: 에디트 모드에서 물리 효과를 줄 표면 정점을 선택하고 등록합니다. (좌/우 자동 분할)
2. **`2. 선택 부위를 강체로 등록`**: 단추, 브로치, 엠블럼 등 늘어나거나 휘어지면 안 되는 단단한 부위를 선택해 강체로 등록합니다.
3. **`3. 가슴 물리 본 생성 (강체 제외)`**: 강체 부위를 제외한 순수 가슴 메쉬 형태만을 분석하여 최적의 위치와 돌출 방향으로 물리 본을 자동 생성합니다.
4. **`4. 본 기준 가중치(웨이트) 자동 계산`**: 본의 위치와 메쉬 형태를 바탕으로 자연스러운 방사형 가중치를 자동 계산하여 적용합니다.

### 2. 형태 보존 강체(Rigid) 보호 시스템
* 가슴이나 의상 위에 얹힌 금속 장식, 단추, 브로치, 지퍼 등이 고무처럼 늘어나지 않도록 **연결된 메쉬 덩어리(Connected Mesh Island) 단위의 통합 강체 클러스터링**을 적용합니다.
* 장식품 전체가 단일 중심 가중치로 회전하여 원래의 단단한 형태를 100% 보존합니다.

### 3. 살 뚫림 방지(Anti-Clipping) 및 매끄러운 가중치 감쇠
* 가슴 모핑 시 몸통 안쪽 살이 튀어나오거나 겨드랑이/밑가슴 메쉬가 찢어지는 현상을 방지하는 지능형 감쇠 알고리즘이 적용되어 있습니다.
* 세부 설정을 통해 가중치 퍼짐 정도(`falloff_power`)를 원하는 스타일에 맞게 부드럽게 조절할 수 있습니다.

### 4. 다중 분리 메쉬 완벽 동기화 (Multi-Mesh Sync)
* 캐릭터 Body, 의상, 가슴 장식 등이 서로 다른 별개의 메쉬 오브젝트로 분리되어 있어도 인접한 정점들의 가중치를 완벽히 일치시켜 경계면이 벌어지거나 찢어지지 않습니다.

### 5. 블렌더 뷰포트 실시간 물리 프리뷰
* 게임을 실행하지 않고도 블렌더 뷰포트 내에서 **통통 튀는 탄력과 관성, 숨쉬기 미동**을 실시간으로 확인하면서 슬라이더 파라미터(강도, 속도, 감쇠, 관성 등)를 취향에 맞게 미세 조정할 수 있습니다.

### 6. 무손실 모드 주입 및 원클릭 롤백
* 모드 폴더 내 `.ini` 파일과 버퍼 데이터를 자동으로 감지하여 3DMigoto 전용 2-Pass Compute Shader와 Map 버퍼를 안전하게 주입합니다.
* **원본 무손실 롤백**: 언제든지 원클릭으로 주입 전 원본 모드 상태로 100% 깨끗하게 복원할 수 있습니다.
* **인게임 실시간 ON/OFF 토글**: 게임 플레이 도중 단축키(기본 `h`)로 물리 적용 전/후를 실시간으로 비교해 볼 수 있습니다.
* **물리 설정 불러오기**: 이미 물리가 주입된 모드 폴더를 선택하면 본 위치와 물리 파라미터를 블렌더로 다시 가져올 수 있습니다.

### 7. 자동 업데이트 지원
* 애드온 내 `업데이트` 패널에서 최신 릴리스 버전을 원클릭으로 확인하고 즉시 자동 업데이트할 수 있습니다.

## 📥 설치 방법

1. GitHub [Releases](https://github.com/DPN-dpn/XXMI-Custom-Physics/releases) 페이지에서 최신 버전의 `XXMI-Custom-Physics.zip`을 다운로드합니다.
2. 블렌더를 실행하고 상단 메뉴에서 `Edit(편집)` > `Preferences(환경설정)` > `Add-ons(애드온)`으로 이동합니다.
3. 우측 상단의 `Install...(설치...)` 버튼을 누르고 다운로드한 `XXMI-Custom-Physics.zip` 파일을 선택합니다.
4. 검색창에 `XXMI Custom Physics`를 검색한 뒤 체크박스를 활성화합니다.
5. 3D 뷰포트에서 `N` 키를 누르면 우측 사이드바에 **`XXMI Physics`** 탭이 나타납니다.

## 🚀 사용 가이드

### 1단계: 가슴 선택 & 본 생성
1. 블렌더 뷰포트에서 모드 캐릭터 메쉬를 선택하고 `Tab`을 눌러 **에디트 모드(Edit Mode)**로 진입합니다.
2. 가슴 표면 정점들을 선택한 뒤 **`[1. 선택 영역을 가슴으로 등록]`**을 누릅니다. (좌우가 자동으로 분할 등록됩니다.)
3. 가슴 위에 단추, 브로치, 장식 등 형태를 유지해야 하는 부분이 있다면 에디트 모드에서 해당 부위를 선택 후 **`[2. 선택 부위를 강체로 등록]`**을 누릅니다. (강체 부위가 없다면 생략 가능)
4. **`[3. 가슴 물리 본 생성 (강체 제외)]`**를 누르면 가슴 형태에 맞게 물리 본(`XXMI_Breast_Rig`)이 자동 생성됩니다.
5. 생성된 본의 위치나 각도를 필요에 따라 미세 조정한 뒤, **`[4. 본 기준 가중치(웨이트) 자동 계산]`**을 누릅니다.

> 💡 **세부 설정 및 관리 도구**:
> 패널 하단의 아코디언을 펼치면 가중치 퍼짐 정도 조절, 가슴/강체 정점 다시 선택, 초기화 등의 편의 도구를 사용할 수 있습니다.

### 2단계: 물리 설정 & 프리뷰
1. **`[뷰포트 실시간 물리 프리뷰 시작]`**을 누르면 뷰포트에서 캐릭터 가슴이 통통 튀는 물리 시뮬레이션이 시작됩니다.
2. 흔들림 크기, 탄력 속도, 출렁임 멈춤 (감쇠), 이동 관성 반응, 숨쉬기 미동 슬라이더를 조절하여 원하는 모핑 스타일을 맞춥니다.
3. 조정이 끝나면 **`[물리 프리뷰 정지]`**를 누릅니다.

### 3단계: 모드에 물리 주입
1. **`대상 게임`**(ZZZ 또는 HSR)을 선택합니다.
2. 폴더 아이콘을 눌러 물리를 적용할 **`모드 폴더`**를 지정합니다.
3. **`[모드에 물리 주입]`** 버튼을 누르면 모든 버퍼와 HLSL 쉐이더가 모드에 적용됩니다.
4. 게임을 실행하여 자연스러운 커스텀 물리를 감상하세요!

## ❓ 문제 해결 (FAQ)

**Q. 인게임에서 옷이나 살이 찢어지거나 틈이 보입니다.**
* 가슴 가중치를 계산할 때 Body 메쉬와 의상 메쉬를 모두 포함하여 진행했는지 확인하세요.
* `세부 설정 및 관리 도구`에서 `가중치 퍼짐 정도`를 조절한 뒤 `[4. 본 기준 가중치(웨이트) 자동 계산]`을 다시 실행해 보세요.

**Q. 단추나 가슴 장신구가 고무처럼 늘어나서 어색합니다.**
* 해당 장신구 정점들을 에디트 모드에서 선택하고 `[2. 선택 부위를 강체로 등록]`을 눌러 등록한 후 본 생성 및 가중치 계산을 다시 진행해 주세요.

**Q. 원래 모드 상태로 되돌리고 싶습니다.**
* 모드 폴더를 선택한 뒤 `3. 모드에 물리 주입` 패널에서 **`[물리 효과 롤백 (원본 복원)]`**을 누르면 주입 전 상태로 완전히 복구됩니다.
